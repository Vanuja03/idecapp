# IDEC mobile app

Expo SDK 54 client for IDEC logistics daily truck jobs.

See the [root README](../README.md) for API setup, seed users, LAN IP configuration, and architecture.

```bash
copy .env.example .env
npm install
npx expo start
```

Set `EXPO_PUBLIC_API_URL` to `http://YOUR_PC_LAN_IP:5000/api` when running on a physical device.
